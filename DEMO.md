# CivicMerge AI — 90-Second Demo

## 0–15 sec: Explain the problem

"Municipal systems receive the same pothole or streetlight complaint many times. That creates duplicate tickets, fragments evidence, and wastes operator time."

## 15–35 sec: Show the first complaint

Submit:

- Category: Pothole
- Description: "Large pothole outside NMIET main gate causing danger to vehicles"
- Location: use a fixed demo coordinate
- Optional: upload a pothole image

Result:

**New master issue created.**

## 35–55 sec: Show AI duplicate fusion

Submit from the same location:

"Bad road hole near the NMIET entrance is damaging vehicles."

Explain that the wording is different but the meaning, category, location, and time align.

Result:

**Existing issue detected — report merged.**

Point out:

- duplicate confidence
- distance
- report count increasing
- priority score increasing

## 55–75 sec: Show the municipal command center

Open the admin dashboard.

Show:

- unique issues
- total citizen reports
- duplicate tickets avoided
- high-priority count
- live issue map
- prioritized operations queue

Change the issue from **Open → Assigned**.

## 75–90 sec: Close with the product value

"Traditional systems turn ten citizens into ten tickets. CivicMerge AI turns ten citizens into one verified issue with ten pieces of supporting evidence, helping cities prioritize real problems faster."
